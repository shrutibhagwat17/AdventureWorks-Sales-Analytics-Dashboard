# 📊 AdventureWorks Sales Analytics Dashboard

## 📝 Project Overview

Interactive Power BI dashboard built using the AdventureWorks dataset to analyze sales performance, customer behavior, product performance, and regional trends.

---

## 🎯 Business Objectives

- Monitor Revenue, Profit, Orders, and Return Rate
- Analyze Product Performance
- Identify High-Value Customers
- Evaluate Regional Sales Trends

---

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Modeling
- Drill Through
- What-If Parameters

---

## 📌 Dashboard Pages

### 📈 Executive Dashboard
- KPI Tracking
- Revenue Trends
- Product Category Analysis

### 📦 Product Detail Dashboard
- Product Drill-Through
- What-If Analysis
- Product Performance Metrics

### 👥 Customer Detail Dashboard
- Customer Segmentation
- Top Customer Analysis
- Revenue per Customer

### 🌍 Geographic Dashboard
- Regional Sales Analysis
- Interactive Map Visualizations

---

## 🔍 Key Insights

- Accessories generated the highest order volume.
- Revenue demonstrated strong growth throughout 2021–2022.
- Certain product categories exhibited higher return rates.
- Customer segments contributed differently to overall revenue.
- Regional performance varied significantly across markets.
